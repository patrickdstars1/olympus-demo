# Olympus Dashboard - demo

An interactive demo of a dashboard I built for monitoring and trading MetaTrader 5 accounts (Python / FastAPI back end, vanilla JavaScript front end).

* Chart candles are real market data (a snapshot, date shown at the bottom of the page). Everything else - accounts, trades, positions, orders - is simulated in the browser.
* No real account is connected and nothing is sent to a broker. Not investment advice.
* Pages: overview, chart (with the order desk), open trades, trade log, analytics, alerts. Thai / English switch at the top left.
